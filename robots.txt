#
# Az automatizált adatgyűjtő (scraper) és AI-tréning botok
# hozzáférése TILTOTT: az oldalon szereplő versenypálya-adatbázis
# saját, jelentős befektetéssel létrehozott szerkesztői összeállítás.
#
# ----------------------------------------------------------
# FONTOS SZERKEZETI SZABÁLY – EZT KÖNNYŰ ELRONTANI
# ----------------------------------------------------------
# Egy bot KIZÁRÓLAG a rá vonatkozó, legspecifikusabb csoportot
# olvassa, és a "User-agent: *" blokkot teljesen FIGYELMEN KÍVÜL
# HAGYJA. Ezért minden nevesített botnál MEG KELL ISMÉTELNI a
# Disallow sorokat – nem elég egyszer, a csillagos blokkba írni.
#
# Korábban ez a hiba benne volt: a Googlebot csoportja csak egy
# "Allow: /" sort tartalmazott, így a Google jogosultnak tekintette
# magát a belső munkafájlok (uj_palyak.json, javaslatok.json,
# tools/verify.mjs) indexelésére is.
#
# A robots.txt önmagában amúgy sem technikai kényszer, csak jelzés.
# A tényleges védelmet a worker.js útvonalszűrője adja, ami ezekre
# az útvonalakra 404-et ad – azt egyetlen bot sem tudja megkerülni.
# Ez a fájl a jóhiszemű keresőmotoroknak szól, hogy ne is próbálják.
# ==========================================================
